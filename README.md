# SINGIL
Baka Nakalimutan Mo? SINGIL Lang! A web-based personal borrowing and repayment tracking system (Django + Supabase PostgreSQL).

## Features (Phase 1: Account Feature)
- Registration with validation and hashed passwords
- Login / Logout
- Role-based dashboards (User and Admin)
- Profile view and edit

## Setup
1. pip install -r requirements.txt
2. Copy .env.example to .env and fill in your values
3. python manage.py migrate
4. python manage.py runserver
